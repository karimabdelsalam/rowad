# نظام إدارة عيادة التغذية والتخسيس 🍏

نظام كامل بالعربي (RTL) لإدارة عيادات التغذية والتخسيس — خفيف وبدون أي مكتبات
خارجية، مصمم للعمل مباشرة على استضافة **cPanel** العادية.

## المميزات

- **المرضى**: ملف كامل لكل مريض (بيانات، حالة طبية، حساسية، هدف) مع بحث سريع.
- **القياسات**: وزن، دهون، عضلات، ماء، محيطات (وسط/أرداف/ذراع/فخذ) + حساب BMI
  تلقائيًا + منحنى تطور الوزن.
- **المواعيد**: عرض يومي مع شريط أسبوعي، حالات (محجوز/تم/ملغي/لم يحضر).
- **الأنظمة الغذائية**: قوالب جاهزة قابلة للتخصيص، إنشاء نظام لكل مريض،
  وطباعة بتنسيق أنيق باسم العيادة.
- **المدفوعات والمصروفات**: تسجيل وتصفية بالفترة مع الإجماليات.
- **التقارير الشهرية**: إيرادات، مصروفات، صافي ربح، مرضى جدد، إحصائيات مواعيد.
- **المستخدمون والصلاحيات**: مدير / أخصائي تغذية / استقبال.

## المتطلبات

- PHP 8.0 أو أحدث (يعمل حتى 8.4) مع امتدادات `pdo_mysql` و`mbstring`.
- قاعدة بيانات MySQL / MariaDB.

## التثبيت على cPanel (5 دقائق)

1. **ارفع الملفات**: من File Manager ارفع محتويات مجلد `clinic/` إلى
   `public_html` (أو مجلد فرعي مثل `public_html/clinic`).
2. **أنشئ قاعدة بيانات**: من cPanel → *MySQL® Databases*:
   - أنشئ قاعدة بيانات جديدة.
   - أنشئ مستخدمًا وكلمة مرور.
   - أضف المستخدم للقاعدة مع صلاحيات **ALL PRIVILEGES**.
3. **شغّل التثبيت**: افتح في المتصفح `https://موقعك/install.php`
   وأدخل بيانات القاعدة واسم العيادة وحساب المدير.
4. **احذف `install.php`** من السيرفر بعد نجاح التثبيت (مهم أمنيًا).
5. سجّل الدخول من `login.php` وابدأ.

> إذا فشل إنشاء ملف الإعدادات تلقائيًا، سيعرض لك المثبّت محتوى الملف —
> أنشئ `inc/config.php` يدويًا والصق المحتوى.

## ملاحظات

- المنطقة الزمنية الافتراضية `Africa/Cairo` — عدّلها في `inc/config.php`.
- النسخ الاحتياطي: من cPanel → phpMyAdmin → اختر القاعدة → **تصدير** (يفضّل أسبوعيًا).
- مجلد `inc/` محمي من الوصول المباشر عبر `.htaccess`.
