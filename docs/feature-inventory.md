# جرد تفصيلي كامل — نظام رواد لإدارة الأملاك

> هذه الوثيقة هي المرجع الملزم عند إعادة بناء النظام على Laravel:
> **كل بند هنا يجب أن يكون له مقابل في النسخة الجديدة** (أو قرار موثّق بإلغائه).
> مستخرجة آليًا من الكود الفعلي (الـ controllers والـ models والجداول) بتاريخ 2026-10-15.

---

## 1. البنية العامة

- **3 بوابات:** لوحة الإدارة `adminarea` (GROUP_ID=1)، بوابة المُلّاك `ownerarea` (GROUP_ID=2)، بوابة العملاء/المستأجرين `clientarea` (GROUP_ID=3) + واجهة عامة `frontend`.
- **REST API جاهز للموبايل:** أي رابط بـ `?output=json` يتحول لـ API — مصادقة بـ `ACCESS-TOKEN` (توكن مستخدم) + `API-KEY` (مفتاح النظام `rest_api_key`). موديول `pns` يسجّل device tokens للإشعارات push — يعني في تطبيق موبايل متصل.
- **لغتان:** عربي (افتراضي) + إنجليزي عبر gettext وملفات `.mo` قابلة للرفع من الإعدادات.
- **تقويمان:** هجري (أم القرى — `HijriCalendar.class.php`) وميلادي، بإعداد `system_calendar` + تقويم منفصل للرواتب `salary_calendar`.
- **Cron ذاتي:** `perminute` (طوابير الإيميل/SMS)، `hourly`، `daily` (تنبيهات الدفعات، انتهاء العقود، التأشيرات، الرخص).

## 2. أنواع المستخدمين والصلاحيات

- مديرون (موديول `manager`): حسابات بصلاحيات تفصيلية لكل موديول/أكشن (`rights` + `loadUserPermissions` / `updateAdminPermission`)، تفعيل/تعطيل، سجل عمليات لكل مدير (`manager/logs` مع فلترة بالموديول الفرعي).
- مُلّاك ومستأجرون ومشترون لهم حسابات دخول (username/password أو **دخول برمز SMS** — إعدادا `smslogin` و`smslogin_clients`).
- **Login-as**: الإدارة تقدر تدخل بحساب أي مالك/مشتري (`loginas` في `owner` و`buyer`) مع `masklogout` للرجوع.
- استرجاع كلمة المرور: بالإيميل (hash) أو **OTP عبر SMS** (`resetbyotp`, `verifycode`)، تسجيل حساب جديد (`newAccount`)، تفعيل بالبريد.
- حماية من تكرار المحاولات (`ProtectFlood`, `login_activity.retries` يتصفّر يوميًا) + سجل نشاط الدخول (`loginActivities`).

### الضرائب (إعدادات عامة تُطبق في العقود والفواتير)

### التقارير (`reports/*` — كلها بعرض وطباعة)
دخل `income`، مصروفات `outgoings`، أرباح `profits`، بنكية `banking`، ضرائب `taxes`، ضرائب شركات `corp_taxes`، تقرير عقار (بمدى شهور)، تقرير وحدات، تقرير مستأجر، تقرير إيجارات. + إحصائيات لوحة التحكم (`collectStats`, `graphicStats` رسوم Chart.js، إحصائيات خاصة بالمالك والعميل).

## 4. بوابتا المالك والعميل

- **بوابة المالك** (`ownerarea` — مجموعة `units` + `property`): عقاراتي، وحداتي، عقود إيجاري وبيعي (عرض + طباعة)، دفعاتي (فلترة بالعقار/المستأجر)، سنداتي قبض/صرف (طباعة)، تقارير عقاراتي، إرسال تذكرة دعم، إحصائيات مالك.
- **بوابة العميل/المستأجر** (`clientarea` — مجموعة `ccp`): وحداتي المستأجرة/المشتراة، عقودي (عرض + طباعة)، دفعاتي وأقساطي، تذاكر دعم.
- كل أكشن فيهما محمي بفحص ملكية (`hasAuth`/`hasAuthContract`) — في لارافيل: Policies.

## 5. الإشعارات (19 حدثًا، كلٌ بقناتي إيميل + SMS بقوالب قابلة للتحرير)

تنبيه قسط إيجار قبل 15 يوم `payRent15`، أقساط بيع (قبل 15/قبل يوم/يوم الاستحقاق/متأخر: `sellPay15/1/0/x`)، تحصيل قسط بيع، انتهاء عقد للمالك وللمستأجر، تأجير عقار المالك، وصول مبلغ للمالك `ownerAmountTo`، عقد إيجار جديد، **انتهاء تأشيرة موظف قبل 15 يوم** `visaEnd15`، **انتهاء رخصة حكومية قبل 15 يوم** `licenseEnd15`، OTP، رمز دخول SMS، استرجاع كلمة مرور، تغيير إيميل، تسجيل جديد. تُرسل عبر طابور (`startQueue`) يعمل كل دقيقة.

## 6. إعدادات النظام (جدول `setting` — 58 مفتاحًا)

هوية: اسم المنشأة عربي/إنجليزي، شعار، عنوانان، هاتف/جوال/فاكس، إيميل، عملة، دولة، كود هاتف دولي، رابط الموقع، معلومات فوترة.
تشغيل: منطقة زمنية، تقويم النظام/الرواتب، لغة وملفا ترجمة، مفتاح خرائط Google، رسالة إغلاق الموقع، إخفاء دليل الاستخدام.
بريد: mail/smtp (سيرفر/منفذ/مستخدم/كلمة سر).
SMS: مزود + حساب + اسم مرسل + دخول SMS للإدارة وللعملاء.
ضرائب: vat + 4 ضرائب بحالة وقيمة.
ترخيص/خطة: purchase_code، rest_api_key، نسخة، حصص (مساحة ملفات `total_file_size`، عدد وحدات `total_units`).

## 7. تكاملات وخدمات

- **SMS — 13 مزودًا:** Unifonic، Mobily (SMS/WS)، Mrasel، Twilio، Nexmo، Clickatell، ClickSend، BulkSMS، SMSGlobal, SMSAPI, MSG91, HDVBX + فحص رصيد.
- **ZATCA** (فاتورة سعودية): QR بصيغة TLV Base64 عبر مكتبة Salla.
- **QR codes:** chillerlan/php-qrcode — للفواتير، للتحقق من العقود، ولحساب المستخدم.
- **بريد:** PHPMailer (SMTP أو mail).
- **Excel:** PhpSpreadsheet — تصدير أي جدول، واستيراد قوائم بريدية.
- **صور:** PhpThumb — تحجيم مع كاش.
- **تشفير روابط:** AES-128 بـ SECRET_KEY (روابط تحقق العقود، login-as…).
- خرائط Google (مفتاح في الإعدادات)، كشف المتصفح، geolocation.

## 8. سلوكيات عامة يجب نقلها

- رفع مرفقات لأي كيان (جدول `attachments` بأنواع مسموحة حسب التصنيف) + Dropzone.
- تصدير Excel وطباعة من أي قائمة، quick-form (نوافذ AJAX)، no_header mode.
- سجل تدقيق لعمليات المديرين `registerLog`.
- نسخ احتياطي DB من الواجهة.
- صفحة صيانة `maintenance_page` عند التحديث.
- ترقيم صفحات بعدد قابل للتغيير `perpage`.

## 9. خريطة النقل إلى Laravel 13

| القديم | الجديد |
|---|---|
| موديول = controller+model+tpl | Module domain: Models + Filament Resources + Policies |
| rights + مجموعات 1/2/3 | spatie/laravel-permission (roles + permissions لكل أكشن) |
| ezSQL + SQL خام | Eloquent + Migrations بعلاقات وفهارس حقيقية |
| Smarty templates | Blade / Filament |
| cron perminute/hourly/daily + silentRequest | Scheduler + Queues (Horizon) |
| notification module + قوالب | Laravel Notifications (قنوات mail + sms مخصصة) + spatie/database-notifications |
| REST API (?output=json + ACCESS-TOKEN) | Sanctum tokens + API Resources (نفس endpoints للموبايل) |
| pns device tokens | FCM عبر laravel-notification-channels/fcm |
| attachments | spatie/laravel-medialibrary |
| manager/logs | spatie/laravel-activitylog |
| sample (قوالب طباعة) | محرر قوالب + Blade render + browsershot/dompdf للـ PDF |
| custom_fields | حزمة custom fields أو جدول EAV مع Filament form builder |
| updatecore (ترخيص/خطة) | لوحة SaaS مركزية: خطط + اشتراكات + حصص (مساحة/وحدات/مستخدمين) |
| setting table | spatie/laravel-settings لكل مستأجر |
| هجري | حزمة تقويم هجري (مثل alkoumi/laravel-hijri-date أو مكتبة أم القرى) |
| ZATCA QR | salla/zatca-php (نفسها) — وجاهزية للمرحلة الثانية (الربط) |
| i18n gettext | ملفات lang لارافيل + Filament translations |

## 10. معيار القبول (Parity Checklist)

النسخة الجديدة لا تُعتبر مكتملة إلا إذا: كل أكشن في §3 و§4 له مقابل، الـ 19 إشعارًا تعمل بالقناتين، الدفع الجزئي والسندات المرتبطة بالبنوك تعمل، QR الفاتورة يطابق مواصفة ZATCA، التقويم الهجري في كل الشاشات والتقارير، بوابتا المالك والعميل بنفس الفحوصات، التقارير العشرة بنفس الأرقام على بيانات مُرحّلة من النظام القديم، وواجهة API تخدم تطبيق الموبايل الحالي أو بديله.
