# رؤية عقار نوفا: ما بعد المطابقة مع النظام القديم

هذه الوثيقة تجيب عن سؤال المالك: **ما الذي ينقص النظام القديم، وما الذي يجعلنا رقم 1 في السوق؟**
السوق السعودي لإدارة الأملاك فيه منافسة قليلة ومنتجات قديمة الشكل؛ الفرصة ليست في "نفس المميزات بشكل أجمل" بل في ثلاثة محاور
لا يملكها أحد اليوم: **الأتمتة، التكامل الحكومي، والذكاء الاصطناعي**.

## 1) ما لدينا اليوم وليس في القديم (جاهز)

| الميزة | الأثر على العميل |
|---|---|
| مساعد ذكي يقرأ بيانات المؤسسة ويجيب ويحلل كل تقرير | قرار أسرع بدون محاسب؛ "من المتأخرون؟ ما أفضل عقار؟" في ثوانٍ |
| ملخص ذكي للمالك والمستأجر في بوابتهما | المالك يفهم حسابه بدون اتصال بالمكتب |
| SaaS متعدد المؤسسات بقاعدة منفصلة لكل مكتب + تسجيل ذاتي + باقات | بيع للمئات بلا تثبيت يدوي |
| تراخيص للنسخ المثبتة عند العميل (للجهات الكبيرة) | سوق ثانٍ بنفس الكود |
| API + رموز دخول للجوال | تطبيق جوال لاحقًا بلا إعادة بناء |
| لوحة منصة احترافية: إيرادات، نمو، صحة النظام، دخول كمدير المؤسسة | تشغيل الخدمة بشخص واحد |
| تصميم حديث متجاوب، عربي/إنجليزي، هجري/ميلادي | يُباع للمكاتب الكبيرة والأجانب |
| حماية: OTP عبر SMS، سجل عمليات، فصل كامل بين المؤسسات | شرط للجهات الحكومية والشركات |

## 2) الناقص في القديم (وفي معظم المنافسين) — الأولوية بالترتيب

### أ. التكامل الحكومي السعودي (الفارق الحاسم)
1. **منصة إيجار (Ejar)**: توثيق عقود الإيجار إلزامي؛ تكامل API لإنشاء/جلب العقد الموثق ورقمه ونسخة PDF → كل مكتب مضطر لفعله يدويًا اليوم.
2. **زاتكا المرحلة الثانية**: التكامل الفعلي (Clearance/Reporting) لا رمز QR فقط — مطلوب تدريجيًا لكل المنشآت.
3. **نافذ / SADAD**: تحصيل الأقساط برابط دفع (سداد، مدى، Apple Pay) مع مطابقة تلقائية للقسط وإصدار سند القبض لحظيًا — ينهي "التحصيل اليدوي" وهو أكبر صداع للمكاتب.
4. **أبشر/نفاذ لتوثيق هوية المستأجر** و**العنوان الوطني** لتعبئة العناوين.

### ب. الأتمتة بدل الإدخال
- قراءة الصكوك والهويات والعقود بالصور (OCR + ذكاء اصطناعي) وتعبئة النماذج تلقائيًا.
- "روبوت التحصيل": تذكير واتساب (WhatsApp Business API) مع رابط دفع، ثم تصعيد تلقائي (رسالة → اتصال → خطاب إنذار جاهز للطباعة).
- توزيع المالك تلقائيًا: تحويل صافي المالك عبر API البنك (مثل تحويلات الراجحي/الأهلي للأعمال) مع كشف حساب مرسَل آليًا.
- صيانة: تذكرة من المستأجر بالصور → تعيين فني → عرض سعر → خصم من المالك أو المستأجر حسب العقد.

### ج. الذكاء الاصطناعي كمنتج لا كميزة
- **تسعير ذكي**: اقتراح الإيجار العادل من بيانات الحي والمنطقة (بيانات مفتوحة + تاريخ المكتب).
- **تنبؤ بالتعثر**: من يتأخر غالبًا الشهر القادم، واقتراح الإجراء.
- **مسودات تلقائية** للخطابات والإنذارات والرسائل بلغة المكتب.
- **تقارير بسؤال** ("كم صافي ربح عقارات جدة في الربع الأخير؟") بدل 10 شاشات تقارير.

### د. التجربة للمستأجر والمالك (هم من يختارون المكتب القادم)
- تطبيق جوال للمستأجر والمالك (PWA أولًا ثم Store): الدفع، التذاكر، العقد، الإشعارات.
- توقيع إلكتروني على العقد من الجوال.
- موقع المكتب العام مع حجز معاينة ودردشة مباشرة ونشر تلقائي للوحدات الشاغرة على عقار/بيوت/حراج عبر API.

### هـ. ما يشتريه المكتب الكبير
- تعدد الفروع تحت مؤسسة واحدة مع صلاحيات لكل فرع، وتقارير موحدة.
- محاسبة كاملة (دليل حسابات، قيود، ميزان مراجعة) أو تكامل مع قيود/Zoho/Odoo.
- لوحة KPIs للمالك المستثمر (العائد على كل عقار، الإشغال، التكلفة لكل وحدة).
- نسخ احتياطي مؤتمت وخصوصية بيانات موثقة (PDPL) — جاهز جزئيًا، يحتاج توثيق وشهادة.

## 3) كيف نصبح رقم 1 (استراتيجية المنتج)

1. **اربح بالتحصيل أولًا**: رابط دفع + مطابقة تلقائية + واتساب. هذه الميزة وحدها تُقنع أي مكتب بالتحول لأنها تلمس الكاش يوميًا.
2. **اجعل إيجار وزاتكا "زر واحد"**: المكاتب تكره الإدخال المزدوج؛ من يلغيه يكسب السوق.
3. **سعّر بالقيمة لا بالعدد**: باقة أساسية رخيصة لجذب الصغار، وباقات بالمميزات (تحصيل، إيجار، ذكاء) — الإيراد يأتي من التحصيل (نسبة أو رسم ثابت على كل دفعة).
4. **البوابة والتطبيق للمستأجر مجانًا دائمًا**: كل مستأجر يصبح مسوقًا؛ وكل مالك يطلب من مكتبه "لماذا لا أرى بياناتي كما في عقار نوفا؟".
5. **الترحيل خلال ساعة**: أداة استيراد من النظام القديم موجودة؛ أضف استيراد من Excel ومن المنافسين، وفريق ترحيل مجاني في أول 3 أشهر.
6. **الثقة**: صفحة حالة الخدمة، نسخ احتياطي يومي معلن، اتفاقية مستوى خدمة، ودعم عبر واتساب داخل اللوحة.

## 4) خارطة الطريق المقترحة (بعد الإطلاق)

| المرحلة | المدة التقريبية | المخرجات |
|---|---|---|
| 1. التحصيل الإلكتروني | 3–4 أسابيع | بوابة دفع (Moyasar/Tap) + روابط دفع في التذكيرات + مطابقة تلقائية + واتساب API |
| 2. إيجار + زاتكا 2 | 4–6 أسابيع | توثيق العقود وإرسال الفواتير حكوميًا من زر واحد |
| 3. تطبيق الجوال (PWA) | 3 أسابيع | المستأجر والمالك: دفع، تذاكر، عقود، إشعارات push (الـ API جاهز) |
| 4. الذكاء التنبؤي والتسعير | 3 أسابيع | تنبؤ التعثر، تسعير مقترح، تقارير بسؤال |
| 5. الفروع والمحاسبة | 4 أسابيع | فروع متعددة، تكامل محاسبي، KPIs للمستثمر |

كل مرحلة تُسلَّم على `main` بنفس القاعدة: اختبارات، لقطات شاشة، وتوثيق في `docs/decisions.md`.
